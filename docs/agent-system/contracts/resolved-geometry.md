# resolved-geometry-v1
Steward: geometry. Consumer: rendering. Capability: geometry.

Inputs: architecture dimensions with evidence statuses, door hinge/width/angles, unknown glazing operation, layout external footprints and facing direction. Coordinates are metres, X right, Y toward balcony, Z up. Outputs: scene.json with architecture/layout/meshes/validation, SVG and OBJ. Renderer must consume resolved geometry and cannot infer missing dimensions. Manifest hashes describe generated bytes, not proof of surveyed accuracy.

Changing units, origin, field meanings, door conventions or mesh semantics is a contract change: mission brief plus geometry/rendering/assurance review. Preserve or explicitly migrate all candidate layouts and tests. Viewer-only camera motion is not a contract change.
