# Decision rights
| Class | One decision owner | Required advice / boundary |
|---|---|---|
| Integrated mission scope and release readiness | Root mission integrator | Catalog reviewers; existing user request bounds authority |
| Geometry schema or calculations | Geometry steward | Rendering and assurance; evidence cannot be fabricated |
| Camera, labels and visual presentation | Rendering steward | Geometry and assurance for derived artifacts |
| Evidence classification of supplied measurements | Diogo Goncalves | Geometry records direct labels/derivations faithfully; new measured confirmation needs traceable human/source evidence |
| Review severity | Independent assurance reviewer | Evidence and reproducible impact; integrator resolves changes |
| Permission expansion, publication, purchases, destructive or external-system actions | Diogo Goncalves | Assurance advice; explicit existing authorization may satisfy the decision |
| Physical construction, electrical, legal or regulated certification | Qualified human professional | Agents prepare context only; never certify |

When authority is absent, finish safe preparation and request the specific missing decision with its source. Do not treat a reference plan as authorization to publish it.
