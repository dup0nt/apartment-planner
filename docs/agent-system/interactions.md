# Interaction and mission lifecycle
The root agent is the integrator for user outcomes. Geometry-as-a-service publishes resolved scene coordinates to rendering. Rendering reports source/scene mismatches rather than adjusting walls. Assurance-as-a-service returns independent severity-ranked findings. Temporary facilitation teaches a new schema; it does not transfer evidence authority.

Start a brief for cross-team, contract, permission, public-claim or architectural work: outcome, scope, steward, consumers, acceptance, evidence, authorization, risks. Time-box collaboration to that mission, integrate one result, run checks, obtain independent findings, resolve blockers and required findings, record residual uncertainty, then close with a handoff. Single-team reversible edits need only the normal task record unless a trigger above applies.

If reviewers disagree, the integrator decides reversible implementation after documenting evidence. User evidence decisions remain human-owned. Never wait for unnecessary unanimity or treat advisory preferences as blockers.

Review evidence must identify the actual reviewer (human or delegated agent), scope, artifacts inspected and returned findings. A writer may perform checks for another capability but cannot call those checks independent review of their own changes. Use a distinct reviewer for assurance. If required specialist review is unavailable, report an interim handoff; do not claim it occurred. One reviewer may explicitly cover multiple capability perspectives in a single bounded review if qualified by the assigned scope.
